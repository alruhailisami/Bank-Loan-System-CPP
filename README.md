# Bank Loans Management System (C++ OOP Implementation)

An Object-Oriented Programming (OOP) core module built in C++ to simulate a banking system. The project handles client details and dynamically calculates loan eligibility and monthly installments based on financial business logic.

## 🌟 Key Features
- **Object-Oriented Design:** Clear class structures utilizing **Inheritance** (`clsLoans` inheriting from `clsClients`).
- **Data Encapsulation:** Safe handling of client credentials and account attributes.
- **Dynamic Calculation Engine:** Real-time computation of maximum loan coverage and monthly installments based on salary (33% debt-to-income limit over 60 months).
- **Clean Architecture:** Modular design prepared for future GUI and database/file integration.

## 🛠️ Built With
- **Language:** C++
- **Concepts:** Object-Oriented Programming (Inheritance, Encapsulation, Method Overriding)

## 📊 Business Logic Overview
- **Monthly Installment:** Calculated dynamically at 33% of the total salary.
- **Loan Capacity:** Equivalent to 60 months of the calculated installment allowance.
